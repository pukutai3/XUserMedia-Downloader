XMD / 01 ブラウザー内で処理

X USER MEDIA DOWNLOADER

過去のメディアを、
このブラウザーから保存。

アプリのインストールも認証情報の登録も不要です。下のボタンをブックマークバーへ一度だけ登録してください。

01

ブックマークへ登録

ボタンをクリックするのではなく、ブラウザー上部のブックマークバーへドラッグします。

↓ Xメディア取得

ブックマークバーがない場合は、リンクをコピーして新しいブックマークのURL欄へ貼り付けます。

  1. 02Xを開く

    メディアを閲覧できるアカウントでログインします。

  2. 03ブックマークを押す

    ユーザー名を入力すると、現在から過去へ取得します。

  3. 04ZIPを保存

    取得とZIP生成はブラウザー内だけで行われます。

認証情報は保存しません

XのCookie、パスワード、トークンをGitHubや外部サーバーへ送信しません。X側の仕様変更やタイムライン制限により、すべての過去投稿を取得できる保証はありません。
